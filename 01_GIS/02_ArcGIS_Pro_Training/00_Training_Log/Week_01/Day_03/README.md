
# Day 03 — Projects & Adding Data

**Date:** 08.07.2026  
**Week:** 01 — GIS & ArcGIS Pro Foundations

## Overview

Day 03 focused on working with ArcGIS Pro projects and adding geospatial data to a project.

The objective was to understand how ArcGIS Pro organizes project-based GIS workflows and how geospatial data is introduced into the project environment.

## Topics Covered

### 1. ArcGIS Pro Projects

- Working with ArcGIS Pro projects
- Understanding the project structure
- Organizing project components
- Working with maps and project content

### 2. Adding Geospatial Data

- Adding data to an ArcGIS Pro project
- Working with geospatial datasets
- Displaying geographic information in the map view
- Exploring added datasets

### 3. Project-Based GIS Workflow

The basic workflow introduced during the day can be summarized as:

**Project**
↓
**Map**
↓
**Add Data**
↓
**Display & Explore**
↓
**Prepare for Analysis**

## Practical Learning

The focus was on moving from the ArcGIS Pro interface toward practical project-based GIS work.

The exercises established the foundation for working with geospatial datasets inside an ArcGIS Pro project.

## Key Learning Outcomes

- Understand the role of an ArcGIS Pro project
- Understand how project components are organized
- Add geospatial data to a project
- Display and explore geographic datasets
- Establish a structured project workflow
