
# Day 10 — Geodatabases, Mosaic Datasets & GeoPackage

**Date:** 17.07.2026

## Overview

Day 10 focused on geodatabases, geospatial data management, mosaic datasets, GeoPackage, and open geospatial data.

## Topics Covered

### Geodatabases

Practical exercise:

Create a geodatabase to support the Salzburg tourism sector.

The exercise focused on using a geodatabase for the creation, storage, and management of geographic datasets for the city of Salzburg.

### Mosaic Dataset

Optional exercise:

- Create a mosaic dataset
- Optional use of a GeoAI model
- Extract roads as vector data using a global roads model

### GeoPackage

Practical exercise:

- Load a GeoPackage onto the remote training PC
- Explore the dataset within the GIS environment

### Open Geospatial Data

- Basis-DLM
