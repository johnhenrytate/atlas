
# Day 16 — Geodata Visualization, Symbology & Cartography

**Date:** 27.07.2026  
**Week:** 04 — Cartography, Labels, Geocoding & Visualization

## Overview

Day 16 focused on the visualization of geospatial data and the design of thematic maps in ArcGIS Pro.

## Topics Covered

### Thematic Cartography

- Visualization of geodata
- Graphics and cartography
- Thematic map design
- Symbolization

### Practical Exercise — Population Map

The main exercise focused on designing the symbology for a thematic map and creating a population map for Indonesia.

### Web Mapping

A second exercise converted a static map into a web application.

The exercise used an existing map of historic cities in Africa and transformed it into an interactive dashboard.

### Additional Activities

- Esri examination sample questions
- Preparation for the following geocoding exercises

## Learning Outcomes

- Understand the role of symbolization in thematic mapping
- Design a thematic map
- Distinguish static and interactive map visualization
- Understand the transition from a static map to a web application/dashboard

## Summary

Day 16 introduced cartographic visualization as a method for communicating spatial information and connected traditional static mapping with interactive web-based visualization.
