A time series was created and visualized.

The practical exercise focused on visitor monitoring and tourism data for New Zealand.

The exercise introduced temporal visualization as a method for representing changes over time.

The optional Esri exercise focused on migrating workflows from ArcMap to ArcGIS Pro.

The exercise aimed to build familiarity with:

- Common GIS tasks in a new interface
- ArcGIS Pro workflows
- Integration with ArcGIS Online
