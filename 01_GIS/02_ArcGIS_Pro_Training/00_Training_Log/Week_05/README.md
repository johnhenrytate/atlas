
# Week 05 — Layout, Map Series, Animation & ModelBuilder

**Training period:** 03.08.2026 – 07.08.2026

Week 05 focused on cartographic layout and map production in ArcGIS Pro, followed by map series, time-based data and animations, and workflow automation using ModelBuilder.

The week also included continued preparation for the Esri examination.
