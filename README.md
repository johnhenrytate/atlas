## 🌎 Project ATLAS

### Greater Memphis — Critical Infrastructure & Spatial Analysis

**Project ATLAS** is my long-term applied geospatial project focused on the Greater Memphis metropolitan area.

The project explores how different spatial datasets can be combined to better understand:

- Critical infrastructure
- Transportation
- Hydrology
- Elevation
- Land cover
- Population
- Environmental factors
- Spatial relationships and accessibility

The project is being developed incrementally as my geospatial skills evolve.

📚 Learning Philosophy

I am following a simple principle:

Don't just learn the tool. Understand the problem it solves.

For each relevant workflow, I aim to document:

Objective → Data → Method → Workflow → Result → Lessons Learned

Whenever possible, I also connect individual techniques to Project ATLAS or another practical use case.

🔬 Reproducibility & Documentation

A major objective of this repository is to develop reproducible geospatial workflows.

I aim to document:

Analytical decisions

Results

Raw source data will not necessarily be stored directly in the repository. Where appropriate, datasets will instead be referenced through their original sources, licensing information, and acquisition details.
